# Nuxt Minimal Starter — Frontend POC PayPal & Stripe

Ce projet est un **Proof of Concept (POC)** frontend minimaliste utilisant Nuxt 3, démontrant l’intégration des solutions de paiement **PayPal SDK** et **Stripe Checkout**.

---

## Objectif

- Intégrer les boutons et flux de paiement PayPal et Stripe côté client.
- Communiquer avec un backend (non inclus ici) pour la création des commandes et la validation des paiements.
- Utiliser Tailwind CSS et Nuxt UI pour une interface simple et responsive.

---
